不是单纯滑雪，是去赴一场雪山之约

03 · THE MOUNTAINS

马特洪峰观光 · 详细游玩手册

Gornergrat是这趟旅行的核心：右侧车窗、山顶列车合照、Rotenboden冬季拍照、雪橇一站接一站；冰川天堂留给另一整天。

2月8日 · 最重要的雪山日

Gornergrat
坐红色齿轨火车去见马特洪峰

从采尔马特火车站对面的Gornergrat Bahn山下站出发。上山坐行驶方向右侧，可以一路欣赏马特洪峰。终点站除了等红色火车入镜，还要留时间走到正规的360°观景平台。

一定选择包含Zermatt ↔ Gornergrat以及Rotenboden ↔ Riffelberg雪橇接驳的 Winter Pass；只有Sledging Pass通常上不到Gornergrat山顶。购票前确认项目和当日开放情况。

2月8日 · 可灵活调整的建议时段

从早上登山到下午雪橇，具体这样走

08:15–09:15

① Zermatt GGB → Gornergrat · 上山看风景

在采尔马特主火车站对面的Gornergrat Bahn入口乘车。列车冬季通常按固定班次运行，不用锁定精确一班；尽量坐右侧靠窗。从Riffelalp往Riffelberg行驶的路段尤其适合从车窗拍雪山和弯道列车。

09:15–10:45

② Gornergrat（3,089米） · 山顶观景＋红色火车同框

先到正式观景平台欣赏马特洪峰、Gorner Glacier和周围群峰；再到有明确开放区域的站台附近寻找雪山＋红色列车构图。可顺带看Golden Spot历史机车展示。山顶建议留60–90分钟，不要只拍一张就走。

10:45–11:50

③ Gornergrat → Rotenboden · 冬季人物摄影

从终点站乘下山列车一站到Rotenboden。站点附近先拍马特洪峰与人物同框。你提供的雪景人物照可以参考构图，但务必只站在开放、安全、维护过的区域。Riffelsee冬季通常结冰并被雪覆盖，不能指望拍到完整湖面倒影，也不要为去湖边穿越深雪。

11:50–12:40

④ Rotenboden → Riffelberg · 午餐休息，领取雪橇

拍完后乘下山火车再一站到Riffelberg。这里是雪橇租借的领取与最终归还点。可以先吃午餐、上洗手间，再领取雪橇。不是在Rotenboden领取。

12:40–15:30

⑤ Riffelberg → Rotenboden（乘火车）→ Riffelberg（滑雪橇）

在Riffelberg拿好雪橇后，带雪橇乘上山火车一站回到Rotenboden，从这里进入官方雪橇道，沿约2公里的路线滑回Riffelberg，落差约233米，单次下滑通常约10分钟。还想再玩，就从Riffelberg继续乘火车上Rotenboden，重复几次。Winter Pass一般包含指定时段内的重复区间火车乘坐和雪橇租赁，仍以当日票面为准。

15:30以后

⑥ Riffelberg归还雪橇 → Zermatt下山

在Riffelberg站把雪橇归还，乘Gornergrat Bahn下山火车回采尔马特镇。雪橇道和山地铁路可能受天气影响，预留足够时间，不必玩到最后一班。

雪橇使用提醒：官方雪橇道从Rotenboden → Riffelberg，不是反方向。携带防滑厚底冬靴、保暖手套，建议佩戴雪上运动头盔；滑雪靴不适合拿来雪橇转向和刹车。雪橇道预计2027年1月根据雪况开放，2月8日仍需当天确认；有大风或能见度差时优先安全。

04 · TWO SKI DAYS

两个雪场，怎么选、怎么玩？

两次都安排私教，先练技术、再看风景。雪道等级是区域内的可选线路，不意味着整片区域全部都是蓝道。

2月7日 · 基础与进阶

Sunnegga · Blauherd

阳光坡面、较友好的学习氛围，适合先让教练评估动作。上山入口就在镇内东北侧。

  • 如何去：步行到Sunnegga地下登山铁路站 → 约4–5分钟到Sunnegga → 需要时继续上Blauherd。
  • 环境：练习区域相对友好，部分雪道有马特洪峰视野，方便休息。
  • 难度：蓝从缓坡开始练，红道无需挑战；由教练挑当天开放且适合的坡段。
  • 建议：09:00–12:00私教，下午重复练习容易控制速度的蓝道。
  • 租赁：FLEXRENT / Bayard Sunnegga，靠近上山入口。

照片说明：你提供的滑雪场景照片用于旅行氛围展示，具体雪道机位未核实。

2月9日 · 高山蓝道

Gornergrat · Riffelberg

更开阔的高山雪景，马特洪峰视觉冲击力强，也可拍到红色登山列车。

  • 如何去：在Zermatt GGB登山火车站上车 → 到Riffelberg下车，与教练集合。
  • 环境：海拔较高、雪景开阔；遇风和低能见度时体感会更冷。
  • 难度：蓝可以循官方初中级蓝道路线练习，但不强求走完整条线路。
  • 建议：上午私教练连续转弯，下午自由练习＋拍照；若疲劳，坐火车下山。
  • 租赁：Bayard Bahnhofplatz，在Gornergrat上山铁路附近。

09 · BEFORE YOU GO

出发前的实用提醒

需要提前订的

✓
2月7、9日ZERMATTERS上午3小时私教：优先锁定两个山上集合点。
✓
民宿地址确定后，按离Sunnegga铁路站或Gornergrat火车站距离选择雪具店。
✓
Bain Bleu的2月11日傍晚时段；避免返程火车太晚到。
✓
雪山观光时看天气和开放情况；晴天优先拍马特洪峰。

冬季安全与拍照

✓
Gornergrat冬季带抓地力好的冬靴、手套，雪橇建议戴头盔；不要穿滑雪靴滑雪橇。
✓
Riffelsee冬季通常冻住并被雪覆盖，没有常见的夏秋湖面倒影。
✓
“隐藏机位”仅走当日开放、标示清楚的冬季步道，不跨越封闭区域。
✓
冰川天堂海拔3,883米，注意保暖、放慢节奏，身体不适及时下山。
